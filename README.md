# 🛍️ RP MODA FEMININA - Loja Virtual & Catálogo WhatsApp

Uma aplicação web completa, moderna e responsiva desenvolvida para a boutique **RP MODA FEMININA**. O sistema funciona como uma vitrine de produtos e sacola de compras integrada diretamente ao **WhatsApp**, contando ainda com um **Painel Administrativo protegido por senha** para gestão de catálogo em tempo real.

## 📸 Funcionalidades

### 🌟 Para as Clientes
- **Vitrine Interativa:** Exibição de produtos organizados por categorias (*Vestidos, Conjuntos, etc.*) e busca dinâmica por palavra-chave.
- **Seleção de Tamanho:** Escolha prática do tamanho desejado (P, M, G, GG) diretamente no card do produto.
- **Atendimento Rápido via WhatsApp:** Botão direto em cada produto para tirar dúvidas ou negociar uma peça individual.
- **Sacola de Compras (Cart Drawer):** Adicione múltiplos itens, ajuste quantidades e preencha os dados de entrega.
- **Checkout Direto:** Envio do pedido formatado com lista de itens, tamanhos, valores e total diretamente para o WhatsApp da loja.

### 🔐 Para a Administração (Painel Admin)
- **Acesso Restrito:** Autenticação por senha para garantir que apenas pessoas autorizadas façam alterações.
- **Cadastro Dinâmico de Produtos:** Adicione novos itens informando nome, preço, categoria, tamanhos e foto (via Link/URL ou Upload local).
- **Gestão de Catálogo:** Lista simplificada para exclusão de produtos cadastrados.
- **Configuração do WhatsApp:** Atualização fácil do número de atendimento da loja diretamente pelo painel.
- **Persistência Local:** Todos os dados cadastrados e itens da sacola são salvos no `localStorage` do navegador.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias puras da Web (*Vanilla JS*), sem a necessidade de frameworks pesados ou gerenciadores de pacotes:

- **HTML5:** Estruturação semântica da aplicação.
- **CSS3:** Estilização personalizada, Layout Grid, Flexbox e Animações.
- **JavaScript (ES6+):** Lógica do carrinho, filtros de busca, integração WhatsApp e manipuladores do `localStorage`.
- **Google Fonts:** Fontes *Playfair Display* e *Poppins*.
- **FontAwesome v6:** Ícones vetoriais modernos.
